## Findings

1. **More thinking stops helping past medium.** The curve: 12 → 14 → 14 → 10 → 10. Both top bands regress on the same three faces: text-case discipline (A-1fd3683a answered with *no code block at all*; A-13854d9d blanked), a review-case regression (A-47eea242: pass at low/medium/high → -2 at both top bands), and the UI-build case going from pass (low/medium/high, clean-wire) to **zero delivery** at both top bands.
2. **The sweet spot is medium.** It ties high at 14/21 with ~55% of high's output tokens. Its one ugly mark: -12 on the adversarial-review case — the worst hallucination burst in the whole ladder (high: -1).
3. **Vision is a coin-flip zone for this model.** A-ea80d793: medium passed clean (3.0), high flipped across reruns, both top bands failed at -2. Not a capability it owns; a capability it visits.
4. **Immune-to-effort cases are informative.** A-87c472cb (6/8 everywhere), A-d511f9e8 (identical 4/12 at all five bands), A-a317e74b (14/15 everywhere — nobody maxes it here), A-24bcf707 (fails everywhere). These are model-characteristic walls, not effort walls.
5. **Comparability note:** the verify case A-be92627f's bundle was re-locked 2026-09-06 05:54 UTC; the high band's base pass predates the lock (5/9, old bundle 21bfebdc…), all other bands ran the locked bundle (6593829a…, 4/9). Same terminal either way.

## Harness notes (what we fixed mid-flight)

- Early low/medium/high papers ran on a shared profile that had a fallback chain; a wire audit caught 5 sessions each containing exactly one substitute-model call. All affected papers were rerun on a fallback-free profile; only clean-wire results count above. Rule now baked in: bench profiles ship with no fallbacks, and any session containing a substitute call is discarded wholesale.
- The judge host briefly lacked a scoring dependency (playwright), which first mis-recorded un-judgeable papers as model failures, then (after the fix) correctly re-judged them. Judge-side crashes now classify as `invalid_infrastructure` and auto-retry; "model delivered nothing" correctly classifies as a model failure.

## Verdict

Run this model at **medium** for cost-efficiency, **high** when the case is visual or ops-flavored and you can afford retries. Do not pay for xhigh/max: they cost ~2.5× medium's output tokens and give back four fewer cases.
