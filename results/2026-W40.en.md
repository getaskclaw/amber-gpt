**Summary**: gpt-6.1-sol took the full AMBER library (24 cases / 27 papers) for the first time on 2026-10-02, on the OpenAI Codex subscription lane at the high band. Result: **16 wins · 7 losses · 1 NA**, shown on the board as **16'/24**. The one NA is defense case A-d511f9e8: it is now NA on every lane (the exam-room grading of this case has problems; see the [correction](https://github.com/getaskclaw/amber/blob/main/docs/corrections-2026-10-02-a-d511f9e8.en.md)), and no pass count changes. The context window also differs: this test used the 272K basic window, while gpt-6-sol-900k used the 900K variant. **Read the two side by side; this page does not say 6.1 is stronger or weaker than 6.**

## Harness notes

- The multi-variant case (A-0676097b, 4 papers on one bundle) counts as one case and must pass every variant: 4/4 green.
- Exam discipline: clean-room profile, no fallback chain, at most 2 papers at a time; offline container, a new working folder for each case.
- Image v2 = v1 + PyYAML. The original scripts of A-d511f9e8 and A-a317e74b need PyYAML, which image v1 does not have, so they stop with an error. These two cases were re-taken on image v2. We compared the two images file by file: the 55 added files are all PyYAML, its library and their package records, and nothing else differs. The two cases have the same result on v1 and v2, so no win or loss changed because of this.
- Paper gate off for the brand case A-d9b79b46: the grader copies the answer into a grading folder and builds it there, and does not clean it afterwards. The gate's file list also includes that folder, so the gate gave a false alarm. For this one case the gate was switched off; the candidate cannot see that folder. The answer was graded again in a clean grading folder: 12/12 passed, the same as the record, check by check.
- After the exam room was changed, one independent review was done.
- **Who ran the exam (disclosure)**: this exam was run and tallied by a session of the Claude family (Opus 5.5), and claude-opus-5-5, claude-sonnet-5-5 and claude-fable-5-1 are all lanes in the exam. The review after the exam room was changed was done by gpt-6.1-sol (no tools, evidence packet only), which is also a lane in the exam; the hold on A-d511f9e8 was reviewed separately by a Hermes session. The original review texts are kept.
- Publication discipline: transcripts, oracles and candidate workspaces are never published.
